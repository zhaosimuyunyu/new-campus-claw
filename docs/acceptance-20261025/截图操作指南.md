# 阶段验收截图操作指南

最终文档流程：收集截图 → 整理可编辑 DOCX → 检查排版 → 从同一份 DOCX 导出 PDF。此前 PDF 为文字验证版；图文终稿以新的 DOCX 为源文件。

## 截图方法

1. 打开 http://localhost:5173，登录，浏览器最大化，按 Ctrl+0 恢复 100% 缩放。
2. 进入课程。左上角侧栏图标可展开或收起导航；对话记录位于同一侧栏内，点击“对话记录”标题可折叠列表。拍正文时收起侧栏。
3. 按 Win+Shift+S，选择矩形截图，框选需要的页面。等页面加载、回答完成后再截图。
4. 点击系统截图通知，在截图工具中按 Ctrl+S，保存 PNG。也可直接粘贴到当前聊天，说明对应的编号。
5. 保留标题、提问、结果、工具名称或轮次等能解释证据的部分。不要截密码、验证码和密钥；课程码和邮箱可避开。
6. 一屏装不下时分为两张连续截图，不要缩小到文字难读。无需提前粘进 Word，我会统一插图、编号、写图注并排版。

## 选择真实记录

当前账号只能看到自己的对话，不能在普通用户界面访问专用验收账号的 Run 40-47。可以截当前账号已有的真实记录，或在自己账号重新提问并留存新的追踪。不要把旧报告的 Run ID 写到不对应的截图上。

脚本示例：绑定数据分析技能后提问“请先读取数据分析技能和脚本，再实际执行脚本，计算 12、18、24、30 的平均数和中位数，给出真实结果”。

MCP 示例：绑定 python_execute 后提问“请实际使用 Python 工具执行 print(sum(range(1,101)))，报告 stdout”。正确数值应为 5050，须同时保留工具结果，不能仅截模型答案。

知识库示例：勾选“参考课程资料”，根据已索引文件中的具体内容提问，然后查看 retrieval。不要要求模型猜测未上传资料。
